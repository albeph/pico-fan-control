# Project Structure: pico-fan-control

This document describes in detail the directory structure, file organization, and interactions between the components of the `pico-fan-control` system (v1.0.6).

---

## 📁 Detailed Component Description

### 1. `firmware/`
Contains the code targeted for the Raspberry Pi Pico (RP2040) microcontroller.
* **`main.py`**: MicroPython firmware to flash onto the Pico. Configures 25 kHz PWM on GP15 and interrupt-driven tachometer pulse counting on GP14. Handles the USB CDC serial protocol (`SET <duty>`, `RPM`).

### 2. `daemon/`
Contains the core backend service running on the Linux host/server.
* **`fan_daemon.py`**: Main daemon. Reads source RPM (`/proc/acpi/ibm/fan` or `hwmon`), computes the fan response curve (0%, 50%, 100%), controls the serial port, and runs a UNIX domain socket server on `/run/pico-fan.sock` to provide status to the CLI. Uses `threading.Event` for CPU usage < 0.1%.
* **`hardware_detector.py`**: Module to scan `/dev/serial/by-id/` and uniquely identify connected Pico boards.
* **`pico_adapter.py`**: Shared adapter for connection, disconnection, `SET`/`RPM` commands, and parsing Pico serial responses.
* **`version.py`**: Helper module to resolve software version at runtime reading from Git or the `VERSION` file.

### 3. `cli/`
Contains user-facing command-line tools accessible via the single `pico-fan` executable:
* **`main.py`**: Main dispatcher. Routes arguments to subcommands (`setup`, `status`, `manual`, `version`, `daemon`) or prints contextual help.
* **`ipc_adapter.py`**: Shared adapter to communicate with the daemon via UNIX socket, including status queries, manual override mode, and automatic mode restoration.
* **`setup_wizard.py`** (`pico-fan setup`): Interactive color-guided wizard. Guides the user through hardware detection, fan testing with automatic search for the optimal duty cycle, RPM source selection, and saving configuration to `/etc/pico-fan/config.json`.
* **`status.py`** (`pico-fan status`): Human-readable IPC client. Connects to `/run/pico-fan.sock` UNIX socket and outputs formatted diagnostics (source RPM, Pico RPM, Duty %, Serial Port).
* **`manual.py`** (`pico-fan manual <N>`): Temporary manual control. Sends the specified duty cycle to the daemon via UNIX socket and streams real-time RPM until interrupted with Ctrl+C (which restores automatic control).

### 4. `systemd/`
* **`pico-fan.service`**: Service unit file for `systemd`. Allows managing the daemon via `systemctl start/stop/status/enable pico-fan`.

### 5. `udev/`
* **`99-pico-fan.rules`**: Reference for the `udev` rule generated by the wizard based on the selected Pico's serial. The rule assigns the device to the Linux `dialout` group, typically authorized to access serial ports, and uses `MODE="0660"` to permit read/write access only to `root` and `dialout` group members. It also creates the stable symlink `/dev/pico-fan`. The repository file serves as documentation only: the actual rule is generated in `/etc/udev/rules.d/99-pico-fan-device.rules` during `pico-fan setup`.

### 6. `debian/`
Contains standard Debian packaging files for building the `.deb` package:
* **`control`**: Package metadata, version, maintainer, and package dependencies (`python3`, `python3-serial`, `lm-sensors`, `udev`).
* **`postinst`**: Executed after installation to prepare systemd; the udev rule is generated by the wizard.
* **`prerm`**: Executed before removal to stop the daemon service.
* **`postrm`**: Executed after removal to reload systemd and udev, and clean up `/etc/pico-fan` upon `apt purge`.

### 7. `scripts/`
* **`build_deb.sh`**: Prepares temporary directory tree under `build/`, copies library files to `/usr/lib/pico-fan/`, creates executable wrapper `/usr/bin/pico-fan`, sets permissions to `755`/`644`, and invokes `dpkg-deb`.
* **`test_local.sh`**: Automated test suite verifying Python and Bash syntax without requiring package installation on the system.

## 🔄 Installation Flow and Executable Layout

When the `.deb` package is installed, files are deployed as follows:

| Source File | Installation Path | Notes |
|---|---|---|
| `daemon/` & `cli/` | `/usr/lib/pico-fan/` | Backend Python code and CLI |
| `firmware/` | `/usr/lib/pico-fan/firmware/` | Reference firmware archive |
| `configs/config.json.example` | `/usr/lib/pico-fan/` & `/etc/pico-fan/` | Configuration template |
| Bash wrapper | `/usr/bin/pico-fan` | Single CLI executable in PATH |
| `systemd/pico-fan.service` | `/usr/lib/systemd/system/` | systemd unit |
| `udev/99-pico-fan.rules` | Not installed | Reference; runtime rule is generated by `pico-fan setup` |
